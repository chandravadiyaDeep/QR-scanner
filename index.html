Project principles

Simple, stable and privacy-conscious.

We are building the product around reliable QR links, secure shop ownership and a customer menu that stays easy to access.

↻

One stable QR link

Changing a price, photo or theme should not force a shop to print a new QR code.

◇

Shop data stays protected

Owner actions are authenticated and shop-scoped. Public customers only receive published menu information.

♡

Free-access commitment

The combined first-release feature set is planned to remain free for shops until the 10,000-shop adoption milestone.

Questions

Good to know.

Do customers need to install the app?

No. The Android app is for shop owners and staff. Customers scan the QR code and open the menu in their normal phone browser.

Will the QR code change when I update my menu?

No. The QR code points to a stable public HTTPS URL. Normal menu edits should not change that URL.

Which languages are planned?

Gujarati, Hindi and English. Shop owners provide translations for their menu content; missing translations fall back to the default language.

Can customers order or pay through the menu?

Not in the current release. The first release focuses on digital menu management and browsing. Ordering and payments are outside the approved scope.

When can I download the Android APK?

The owner app is still in development. The download button will be activated after a tested APK is published in GitHub Releases.

Where can I follow development?

Visit the project's GitHub repository to see implementation progress, issues and release announcements.
